## 一、先选一个小任务

从高频、输入明确、结果容易核对的任务开始。下面每项都给出输入和交付物；若只是固定转换，用普通程序或单次模型调用也可能足够。

## 二、知识与学习（01—10）

| 编号 | 场景 | 输入 → 交付物 |
| --- | --- | --- |
| 01 | 外文精读 | 原文与水平 → 摘要、词汇、理解题 |
| 02 | 文档问答 | 问题与授权资料 → 带出处回答 |
| 03 | 课程规划 | 基础与学习目标 → 阶段练习与验收 |
| 04 | 错题整理 | 错题与解答 → 错因分类与同类练习 |
| 05 | 术语解释 | 术语与上下文 → 白话解释与例子 |
| 06 | 论文阅读 | 论文与问题 → 方法、证据、局限 |
| 07 | 阅读比较 | 多份文章 → 观点差异与原文引用 |
| 08 | 知识更新 | 新旧文档 → 变化清单与待核对项 |
| 09 | 学习测验 | 已学内容 → 题目、答案与解释 |
| 10 | 资料索引 | 一组文档 → 主题目录与可检索条目 |

| 20 | 产品使用指导 | 型号与问题 → 对应版本操作步骤 |

## 七、选好场景后写任务卡

选一项，填写目标、输入、工具、输出、停止条件和验收标准。先用五个代表性例子测试；需要写入业务系统或对外发送时，把确认动作设计在执行之前。

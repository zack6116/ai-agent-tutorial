## 三、从API到Agent

API 返回一次确定的操作结果。Agent 把多个操作与当前任务状态连接起来。以订单查询为例：API 接收订单号返回状态；Agent 还需要判断缺少什么信息、是否查到、是否需要查政策，以及何时结束。

先单独测试 API，再接模型，再增加任务循环，最后接页面。每一层都有可观察结果时，出了问题才能找到对应位置。

## 四、Coze / 扣子教程学习路径

1. 概览与介绍：阅读 [工作流思路](./04-coze-workflow#step-0-梳理手捏-ai-agent-的思路)。
2. 快速开始：输入一篇短文，跑通开始节点到结束节点。
3. 核心功能与应用：接 [页面事件和变量绑定](./05-coze-app)。
4. 案例库：参考 [50个应用场景](./19-scenarios) 选择第二个任务。
5. Agent作品集：按本页模板整理一次成功与一次失败的运行证据。

## 五、把失败也放进作品集

“模型生成了一个看似合理的结果”不能说明任务完成。记录你遇到的字段错误、超时、空结果或循环问题，以及修复前后的相同输入输出。真实的失败分析比没有依据的提升百分比更能说明工程能力。
